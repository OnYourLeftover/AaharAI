# AaharAI - Project Specification

## Objective
Build a vision-based Indian recipe recommendation
and nutrition estimation system.

## Mode A: Dish Recognition
Input: Image of an Indian dish.
Output: Predicted dish and nutrition information.

Model: EfficientNet-B0

## Mode B: Ingredient Recognition
Input: Image of ingredients in a fridge or kitchen.
Output: Detected ingredients and recommended recipes.

Model: OWLv2

## Backend
Python, FastAPI, SQLAlchemy, SQLite.

## Database
Indian Nutrient Databank (INDB).

## Development principle
Build, test and integrate one module at a time.
